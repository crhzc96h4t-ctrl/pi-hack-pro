Waarom Home Assistant?

Een iPhone-browser mag niet zomaar elke tv op het lokale netwerk benaderen. Home Assistant vormt een beveiligde, compatibele brug naar tv's waarvoor jij bediening hebt ingesteld. Niet elk tv-model ondersteunt alle functies.

Netwerk- en apparaatdetectie

Safari op iPhone geeft websites geen algemene toegang tot Wi-Fi-netwerklijsten, IP-range-scans, monitor mode of packet capture. Deze functies kunnen daarom niet betrouwbaar als pure PWA worden uitgevoerd.

Gebruik de router of Home Assistant om apparaten op je eigen netwerk te inventariseren.

Home Assistant verbinding

Gebruik bij voorkeur een HTTPS-adres met geldig certificaat. Deel je token nooit. Deze wordt alleen in de lokale browseropslag van dit apparaat bewaard.

IR-afstandsbediening

Je iPhone heeft geen ingebouwde IR-zender. Voor infrarood heb je een externe Wi-Fi-IR-bridge nodig (bijvoorbeeld een compatibel apparaat met Home Assistant-integratie). Stel die bridge in Home Assistant in; daarna kan PI-HACK PRO de gekoppelde tv via Home Assistant bedienen.
